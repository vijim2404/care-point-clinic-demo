# CarePoint Multispeciality Clinic — Website Demo

## Project Overview
CarePoint is a fictional multispeciality clinic website created as a web design portfolio project. It features a clean, modern, and professional healthcare design.

## Live Website
https://care-point-clinic-demo.pages.dev

## Features
- Modern healthcare homepage
- Medical services section
- Sample doctor profiles
- About the clinic section
- Appointment enquiry form preview
- Responsive design for desktop and mobile devices
- Professional blue-and-white color scheme

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Cloudflare Pages

## Project Status
Completed — Live Demo Available

## Important Notice
This website is a fictional clinic demonstration created for portfolio purposes. Doctor profiles and images are illustrative. The appointment enquiry form is a demo and does not submit real bookings or store user information.
